## **～项目概述～**

「精简像素体 10」是基于「[PixelMplus](https://github.com/itouhiro/PixelMplus)」和「[精品點陣體9×9](https://github.com/scott0107000/BoutiqueBitmap9x9)」将字形修改为更接近中国大陆标准的10px像素字体，适合在像素风游戏或追求科技感的平面设计场景使用。

原字体和上游字体都是非常有特色的字体，像素画、游戏、原创MV、活动宣传、VOCALOID曲目的PV里都能看到原字体的身影。

希望本字体项目能为各个领域添砖加瓦。

如果需要进行繁体排版，推荐各位使用上游字体「[精品點陣體9×9](https://github.com/scott0107000/BoutiqueBitmap9x9)」。

目前本字体项目尚未完工，且仍在持续更新，欢迎各位网友提出宝贵意见。
